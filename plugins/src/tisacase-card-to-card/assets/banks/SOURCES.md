# Bank marks

Source: https://github.com/masihgh/iranian-bank-list/tree/1691d3c760e4a87008fa21ff49122c7d316593f1/images

Copyright (c) 2024 MasihGhaznavi. Distributed under the included MIT license.
37 original static SVGs are bundled locally (17 added in v1.4.0). No runtime image
service, remote fonts inside logos, scripts or analytics are used.

Bank names and marks remain the property of their respective owners. Their use is
identification only and does not imply endorsement, affiliation, banking licence,
current operating status, account ownership, BIN detection or bank verification.
The catalog includes bank/institution names, Blu as a brand, and historical names
in a separate picker group; it is not a current register of licensed institutions.
The upstream Central Bank and Shetab network symbols are intentionally not offered
as destination banks.

`TCC_Helpers::bank_catalog()` is the single source for picker labels, groups,
legacy aliases and allowlisted asset filenames. Unknown historical names retain
the generic icon; a new nonempty unknown name cannot be saved. Existing names can
be preserved verbatim only for the same existing card number. Order snapshots are
never migrated or renamed. Bank name is still optional, as in earlier releases.
