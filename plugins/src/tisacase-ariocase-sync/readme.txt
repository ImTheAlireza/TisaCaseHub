ایمپورت کدمحور، اتصال محصولات موجود و خواندن زندهٔ موجودی از WooCommerce REST API در ArioCase.

== Description ==

این افزونه فقط محصولات/تنوع‌های دارای کد مشخص را به ArioCase وصل می‌کند.

* پیش‌نمایش قبل از هر ایمپورت یا اتصال و خواندن دوبارهٔ دادهٔ تازه هنگام اجرا.
* جست‌وجوی فقط SKU انتخابی؛ دانلود کل فهرست محصولات لازم نیست.
* عدم ساخت محصول تکراری وقتی SKU یا اتصال کد در ووکامرس موجود است.
* ایمپورت محصول ساده و متغیر به‌صورت پیش‌نویس.
* دریافت جزئیات تنوع‌ها با Parent ID و نگاشت جداگانهٔ هر Variation با SKU دقیق.
* نگهداری Product ID و Variation ID برای خواندن مستقیم موجودی در درخواست‌های بعدی.
* کنترل موجودی در افزودن به سبد، سبد و تسویه‌حساب با تجمیع تعداد هر قلم.
* عدم تبدیل Timeout، خطای HTTP یا JSON خراب به موجودی صفر.
* ذخیرهٔ تغییرهای معتبر با CRUD ووکامرس و همگام‌سازی وضعیت والد.
* اتصال دستی SKU محلی به کد متفاوت ArioCase.
* گزارش ۱۰۰ رویداد آخر بدون ذخیرهٔ API Key.
* ثبت خودکار در TisaCase Hub.

== Installation ==

1. ووکامرس را فعال کنید و از سایت نسخهٔ پشتیبان بگیرید.
2. فایل `tisacase-ariocase-sync.zip` را از مسیر پیشخوان › افزونه‌ها › افزودن › بارگذاری نصب و فعال کنید.
3. به ووکامرس › اتصال ArioCase › تنظیمات API بروید.
4. آدرس پیش‌فرض ArioCase را حفظ کنید و توکن JWT را در فیلد API Key وارد کنید؛ روش احراز هویت باید Bearer باشد.
5. تنظیمات را ذخیره و با یک کد واقعی «تست اتصال» را اجرا کنید.
6. در تب «ایمپورت و اتصال» کدها را وارد و پیش‌نمایش بگیرید؛ سپس ردیف‌های تأییدشده را اجرا کنید.
7. ابتدا روی Staging، محصولات ساده/متغیر و مسیر خرید را با دادهٔ واقعی بررسی کنید.

== ArioCase API contract ==

تنظیمات پیش‌فرض نسخهٔ ۱٫۱٫۰ برای قرارداد اعلام‌شدهٔ ArioCase آماده شده است:

* Base URL: `https://ariocase.com/wp-json/wc/v3`
* Auth: `Authorization: Bearer YOUR_TOKEN`
* جست‌وجوی کد انتخابی: `products?status=publish&per_page=100&sku={code}`
* دریافت محصول با شناسه: `products/{id}`
* دریافت جزئیات تنوع‌ها: `products/{parent_id}/variations?status=publish&per_page=100&page={page}`
* دریافت موجودی یک تنوع: `products/{parent_id}/variations/{variation_id}`

افزونه پاسخ List را دوباره با SKU دقیق و حساس‌به‌حروف بررسی می‌کند. شناسهٔ عددی فقط بعد از تطبیق کد ذخیره و استفاده می‌شود. برای بیش از ۱۰۰ تنوع، Pagination انجام می‌شود؛ بیش از ۲۰۰۰ تنوع در یک محصول برای جلوگیری از ایمپورت بسیار سنگین رد می‌شود.

برای اتصال دستی یک Variation، ابتدا محصول والد را از مسیر ایمپورت/اتصال متصل کنید تا افزونه بتواند Parent ID و Variation ID را از API شناسایی کند.

مسیرهای پیشرفتهٔ JSON برای فیلدهای غیرمتداول همچنان قابل تنظیم‌اند. نام‌های `sku`, `name`, `stock_quantity`, `stock_status`, `regular_price`, `variations`, `attributes` و `images` به‌صورت خودکار خوانده می‌شوند.

== Security and stock behavior ==

* HTTPS الزامی است؛ Redirect در فراخوانی API دنبال نمی‌شود تا توکن به مقصد دیگر منتقل نشود.
* توکن نمایش داده نمی‌شود و از پیام‌های خطا و گزارش‌ها حذف می‌شود.
* می‌توانید توکن را با ثابت `TISACASE_ARIOCASE_API_KEY` در wp-config.php بگذارید تا در فیلد دیتابیس نگهداری نشود.
* خطای API هرگز به معنای موجودی صفر نیست و باعث بازنویسی صفر در دیتابیس نمی‌شود.
* با نگهبان خرید فعال، اگر موجودی هنگام خرید قابل بررسی نباشد، خرید قلم متصل متوقف می‌شود.
* حذف افزونه، نگاشت‌ها، شناسه‌های ArioCase و تنظیمات را پاک می‌کند ولی محصولات و موجودی ووکامرس را حذف نمی‌کند.

== Frequently Asked Questions ==

= آیا موجودی بعد از فروش در تیساکیس در ArioCase هم کم می‌شود؟ =
نه، نسخهٔ ۱٫۱٫۰ مسیر خواندنی ArioCase → TisaCase را پیاده می‌کند. نوشتن/رزرو اتمیک در ArioCase بدون Endpoint و قرارداد مشخص عمداً انجام نمی‌شود. بنابراین این نسخه سینک دوطرفهٔ کامل یا رزرو اتمیک آخرین قلم را ادعا ندارد.

= آیا همهٔ درخواست‌ها به API می‌روند؟ =
فقط خواندن موجودی محصولات متصل. در هر Request برای هر محصول حداکثر یک State زنده ساخته می‌شود. پس از ذخیرهٔ ID، محصول ساده و تنوع معمولاً با یک HTTP Request خوانده می‌شوند. Resolve اولیهٔ تنوع بدون ID می‌تواند به دریافت والد و جزئیات تنوع نیاز داشته باشد. از تنظیمات می‌توانید دامنه را به صفحهٔ محصول/سبد/تسویه محدود کنید.

= اگر کد محلی و ArioCase متفاوت باشد؟ =
از تب «محصولات متصل» اتصال دستی بسازید. برای محصول متغیر، هر Variation جداگانه نگاشت می‌شود؛ در اتصال دستی تنوع، ابتدا والد را متصل کنید.

= آیا با سرویس واقعی تست شده است؟ =
قرارداد و Payloadهای WooCommerce در تست‌های خودکار پوشش داده شده‌اند، اما محیط ساخت اجازهٔ اتصال خروجی به ariocase.com نداشت. تست اتصال داخل سایت و بررسی روی Staging پیش از Production الزامی است. توکن واقعی در سورس و بسته ذخیره نشده است.
